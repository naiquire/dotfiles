## my dotfiles and configuration for arch/hyprland

main branch is for my desktop, and alt branch for my laptop

will try to keep merges between these branches up to date

programs you use can be easily changed in one location at the top of hyprland.conf

wallpaper and colour palette generation is currently done through matugen cli because i don't want to learn quickshell

i will port over to lua from hyprlang soon. trust.
## Dependencies
- hyprland ~ compositor
- waybar ~ status bar
- dunst ~ notifications
- matugen ~ colour palette
- awww ~ wallpaper
- hyprshot ~ screenshots
- wf-recorder ~ screen recording
